# SMS2GS
SMS2GS is an Android app that reads incoming SMS messages that match user‑defined rules and automatically sends the data to your personal Google Spreadsheet

## Website

This repository includes a responsive recreation of the public SMS2GS Home page using only HTML, CSS, and browser-side JavaScript. No Node.js, build step, or server is required. Open `index.html` directly in a browser.

The site includes the Home page, Privacy Policy page at `privacy-policy.html`, and Terms of Service page at `terms-of-service.html`.
